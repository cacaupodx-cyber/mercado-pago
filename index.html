Como utilizar seu ID Santander

1. Abra o app Santander no seu celular e selecione o ícone ID Santander.

2. Posicione a câmera do seu celular e capture a imagem QR Code dinâmico exibida na tela do seu computador. Em seguida clique em gerar código de validação.

3. Digite na tela do seu computador o código de validação exibido no seu celular.

Na confirmação de algumas transações, poderão ser solicitadas validações adicionais como um código recebido por SMS e/ou a senha de seu cartão.

Como utilizar seu Token ID

1. Pressione o botão inferior. Ao fazer isso seu Token estará preparado para fazer a leitura.

2. Posicione o Token ID sobre a área cinza e clique no botão 'iniciar'. Aguarde 3 segundos para realizar a leitura.

3. Digite na tela do seu computador o código que aparece no visor do Token e clique no botão 'enviar'.

Na confirmação de algumas transações, validações adicionais podem ser necessárias, como um código recebido por SMS e/ou a senha de seu cartão.

Como desbloquear o seu cartão

No seu kit de Abertura de Conta, está
o Guia Prático para você acessar o Banco
com o código para desbloquear o cartão.

Esse código expira em 20 dias e
só será utilizado uma única vez.
